produces a correctly aligned, scrolling directory listing rendered entirely by the new
D3D11 backend with DirectWrite-rasterized glyphs.

## 6. Learnings for the plan

**Three instrumentation traps, each of which produced a false conclusion I had to retract.
These cost most of the session.**

1. **libghostty logging is off in our builds.** `global.zig` defaults stderr logging to
   `build_config.app_runtime != .none`, and we build `-Dapp-runtime=none`. Log probes are
   silent. I read that silence as "this code never runs", concluded the render pass was not
   executing, and wrongly cast doubt on Phase 1's exit criteria. Set `GHOSTTY_LOG=stderr`.
   (Session 0003 already used this; the knowledge was not carried forward.)
2. **`PrintWindow` cannot capture the D3D11 backend.** Flip-model and DirectComposition
   surfaces are composited by DWM outside the GDI paint path, so it returns the window
   brush regardless of what the GPU drew. This produced a *second* false negative on top of
   the first. `harness/wgc-shot` now exists for this and is window-scoped, which keeps the
   security property that ruled out `CopyFromScreen` after the session 0001 incident.
3. **A missing viewport is invisible.** D3D11 starts with none bound;
   `ClearRenderTargetView` ignores it while every draw is clipped entirely by it. The
   result looks like a correctly cleared, healthy surface that silently refuses to draw,
   with **no D3D error at all**. `RSSetViewports` was only called from
   `Device.bindRenderTarget`, which had no callers.

The common failure was treating absence of signal as evidence about the code instead of
first validating the instrument. Two further claims were asserted as findings when they
were guesses — that RDP explained the blank window, and that a second window was a leaked
conhost (it is the harness's own console, subsystem 3). Both were wrong.

**Other learnings:**

- `fxc /WX` caught a real defect the GLSL carries silently: `pow` on a possibly-negative
  base. HLSL's `lerp` evaluates both branches, so a NaN from the *unselected* branch
  propagates. Worth keeping `/WX`.
- The `Globals` cbuffer must be verified against the Zig `Uniforms` by *reflection*, not by
  reasoning. Two traps: `bools` is four separate bytes here but a bitmask in GLSL, and
  `Mat` stores columns (matching HLSL's default `column_major`).
- Key mapping must go scan-code → key, not VK → key: ghostty's enum is W3C
  `uievents-code`, i.e. physical positions.
